\# Docker Class Project ## Project Overview This project demonstrates Docker containerization with 5 progressive levels, from simple to advanced. ## 5 Dockerfiles Explained ### Level 1: Basic Node.js App - \*\*Purpose\*\*: Learn Docker basics - \*\*Features\*\*: Simple console output - \*\*Dockerfile\*\*: Copies app.js and runs it - \*\*Port\*\*: N/A (console app) ### Level 2: Simple Web Server - \*\*Purpose\*\*: Learn port mapping - \*\*Features\*\*: Single route web server - \*\*Dockerfile\*\*: Exposes port 3000 - \*\*Port\*\*: 3000 - \*\*Command\*\*: `docker run -d -p 3000:3000 --name level2-container level2-app` ### Level 3: Multi-Route Web App - \*\*Purpose\*\*: Learn routing - \*\*Features\*\*: 3 different routes (/, /hello, /about) - \*\*Dockerfile\*\*: Exposes port 3001 - \*\*Port\*\*: 3001 - \*\*Command\*\*: `docker run -d -p 3001:3001 --name level3-container level3-app` ### Level 4: Environment Variables - \*\*Purpose\*\*: Learn configuration - \*\*Features\*\*: Uses APP\_NAME and APP\_VERSION variables - \*\*Dockerfile\*\*: Exposes port 3002 - \*\*Port\*\*: 3002 - \*\*Command\*\*: `docker run -d -p 3002:3002 -e APP\_NAME="MyApp" -e APP\_VERSION="2.0.0" --name level4-container level4-app` ### Level 5: JSON API (Advanced) - \*\*Purpose\*\*: Learn API development in Docker - \*\*Features\*\*: 3 JSON API routes (/api/status, /api/info) - \*\*Dockerfile\*\*: Exposes port 3003 - \*\*Port\*\*: 3003 - \*\*Command\*\*: `docker run -d -p 3003:3003 --name level5-container level5-app` ## Key Docker Commands | Command | Purpose | |---------|---------| | `docker build -t name .` | Build an image | | `docker run -d -p 3000:3000 name` | Run a container | | `docker ps` | List running containers | | `docker ps -a` | List all containers | | `docker images` | List all images | | `docker stop name` | Stop a container | | `docker rm name` | Remove a container | | `docker logs name` | View container logs | ## Screenshots Included -
