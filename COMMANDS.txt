1. docker build -t image-name . - Builds a Docker image from a Dockerfile - -t = tag name for the image - . = use Dockerfile in current folder 2. docker run -d -p 3000:3000 --name container-name image-name - Runs a Docker container from an image - -d = run in background (detached) - -p 3000:3000 = map port 3000 (computer) to 3000 (container) - --name = give the container a name - -e VAR=value = pass environment variables 3. docker ps - Shows all RUNNING containers 4. docker ps -a - Shows ALL containers (running and stopped) 5. docker images - Shows all Docker images on your computer 6. docker stop container-name - Stops a running container 7. docker rm container-name - Removes a stopped container 8. docker logs container-name - Shows error messages from a container DOCKERFILE STRUCTURE ==================== FROM node:18-alpine → Start with Node.js image WORKDIR /app → Create working folder COPY app.js . → Copy your app file EXPOSE 3000 → Tell Docker which port the app uses CMD ["node", "app.js"] → Command to run when container starts PROJECT LEVELS ============== Level 1: Simple Node.js app (outputs text) Level 2: Web app with 1 route (port 3000) Level 3: Web app with 3 routes (port 3001) Level 4: App with environment variables (port 3002) Level 5: JSON API with multiple routes (port 3003)
